# **App Name**: TrendLens

## Core Features:

- Dashboard Overview: Dashboard to display key metrics like total sales, average rating, and discount rates.
- Sales Trend Charts: Interactive charts for visualizing sales trends over time.
- Category Analysis Table: Display a list of product categories and their sales performance.
- Automated Insight Generation: Use an AI tool to automatically provide insights from the data, suggesting potential reasons for sales increases/decreases, or how specific categories are performing.

## Style Guidelines:

- Primary color: White or light gray for a clean background.
- Secondary color: A muted blue or green for charts and graphs.
- Accent: A bright teal (#008080) for interactive elements and highlights.
- Use a grid-based layout to organize the dashboard elements.
- Use simple, line-based icons to represent different metrics and categories.
- Subtle transitions when loading data or switching between views.

## Original User Request:
E-commerce Product Analysis
Goal: Analyze sales, ratings, discounts, and category trends.
Tools: Excel, Power BI / Tableau
Dataset: Kaggle E-commerce, Amazon Product Reviews
